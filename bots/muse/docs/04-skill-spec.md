# 04 — Skill spec

Target path: `~/workspace/skills/openllm/`

## Layout

```
openllm/
  SKILL.md            # Purpose / Tooling / Auth / Operating Rules
  bin/openllm_cli.py  # the CLI (see templates/bin/)
  references/         # only if SKILL.md gets too long; keep it lean
```

`Tooling` and `Auth` are generated by the scaffold (see
`03-credential-setup.md`). You write **Purpose** and **Operating Rules**, and
the CLI in `bin/`.

## SKILL.md frontmatter

```yaml
name: openllm
description: Send prompts through the user's openllm.sh gateway — any model or
  fallback chain behind one sk-llm key. Use when the user asks to run a prompt
  on a specific model, compare models, or route work through their LLM gateway.
```

## CLI contract

`bin/openllm_cli.py` (stdlib only — `urllib`, `json`, `argparse`):

- `chat --model <id-or-chain> --message <text> [--system <text>]
  [--max-tokens N] [--temperature T]`
  → `POST {base}/chat/completions`, prints the assistant text plus a small
  JSON footer: model actually served, tokens used, latency.
- `models` → `GET {base}/models`, prints available model/chain ids.
- `--base-url` flag (or `OPENLLM_BASE_URL` env). Default comes from the
  dashboard value recorded at setup — never hardcode a guess.
- Auth: key is injected by the generated auth helper at call time. The CLI
  must never log, print, or persist the key.

Compile check after writing: `python3 -m py_compile
~/workspace/skills/openllm/bin/*.py`.

A fill-in starting point is in `templates/SKILL.md` and
`templates/bin/openllm_cli.py`.

## Operating rules (put these in SKILL.md)

1. Check spend state before large or batched jobs; refuse or ask first if the
   scoped key is near its cap.
2. Prefer the user's named fallback chains over single models when they exist.
3. Report which hop served the request (the gateway tells you) — never present
   a fallback-served answer as if the requested model produced it.
4. Never include the key, prompts, or completions in logs, files, or memory.
   Metadata only (model, tokens, latency, cost).
